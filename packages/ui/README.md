# @akaya/ui

Akaya design system, shared by the app and both agent frontends: tokens (light/dark), global CSS, `Pearl`, `Icon`,
`Sheet`, `Toast` (with an optional action button, e.g. **Undo**), controls and screen chrome.

Source-only (TSX + CSS): Vite apps import it directly, so there is no build step. Add an icon to `src/components/Icon.tsx`
once and every app gets it.
