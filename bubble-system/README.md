# Bubble system

The Akaya bubble character: a self-contained HTML/JS demo of its states (idle, listening, thinking, speaking, alert and
so on), moods and sound effects. There is no build step.

- `demo/index.html`: open it in a browser
- `demo/akaya-bubble.js`, `akaya-state-machine.js`, `akaya-sfx.js`: the component, the state machine and Web Audio SFX
- `demo/README.md`: API and states
- `assets/`: logo marks used by the demo
- Designs: `../design/bubble-system/` · Video: `../marketing/videos/bubble-system-demo.mp4`

The app's pearl orb (`app/src/components/Pearl.tsx`) is the in-app counterpart. The bubble is not wired into the app yet.
